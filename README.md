# prompts-and-skills

A lightweight repository for collecting and organizing useful prompts and skills.

## Structure

```text
.
├── prompts/
│   └── README.md
└── skills/
    └── README.md
```

## How to use

- Put reusable prompt definitions in `prompts/`.
- Put reusable skill descriptions/playbooks in `skills/`.
- Keep entries small, practical, and easy to copy.

## Suggested entry format

For each prompt or skill, create one Markdown file with:

- `Name`
- `Purpose`
- `When to use`
- `Content` or `Steps`
- `Example` (optional)
