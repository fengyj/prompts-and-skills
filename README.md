# prompts-and-skills

A lightweight repository for collecting and organizing useful prompts and skills.

## Structure

```text
.
├── prompts/
│   └── README.md
└── skills/
    ├── README.md
    └── hv-analysis/
        ├── SKILL.md
        ├── references/
        │   └── schema.json
        └── scripts/
            └── md_to_pdf.py
```

## How to use

- Put reusable prompt definitions in `prompts/`.
- Put reusable skill descriptions/playbooks in `skills/`.
- Keep entries small, practical, and easy to copy.

## Included skills

- `skills/hv-analysis`: A Chinese deep-research skill based on Horizontal-Vertical Analysis, with a full research playbook, analysis schema, and a Markdown-to-PDF converter script.

## Suggested entry format

For each prompt or skill, create one Markdown file with:

- `Name`
- `Purpose`
- `When to use`
- `Content` or `Steps`
- `Example` (optional)
