# Skills

Store skill files here.

## Available skills

- `hv-analysis`: 横纵分析法深度研究 skill，用于对产品/公司/概念/人物做纵向+横向分析，并支持将 Markdown 报告转换为 PDF。

## Template

```md
<What this skill helps accomplish>

## When to use
<Situations where this skill is useful>

1. <Step 1>
2. <Step 2>
3. <Step 3>

## Notes (optional)
<Extra tips or constraints>
```
